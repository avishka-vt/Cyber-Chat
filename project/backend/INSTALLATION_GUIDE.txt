================================================================================
DETAILED SETUP GUIDE
================================================================================

STEP 1: PREREQUISITES
- Python 3.8+ installed
- pip package manager
- Google Gemini API key (free at https://ai.google.dev/)
- Supabase account with project credentials

STEP 2: GET YOUR CREDENTIALS
- Google Gemini API Key: https://ai.google.dev/ → Get API Key
- Supabase URL: Your project → Settings → API → Project URL
- Supabase Anon Key: Your project → Settings → API → Anon public key
- Supabase Service Key: Your project → Settings → API → Service role secret

STEP 3: CONFIGURE ENVIRONMENT
a) Copy template:
   $ cp .env.example .env

b) Edit .env file with your credentials:
   FLASK_ENV=development
   FLASK_DEBUG=True
   PORT=5000
   GEMINI_API_KEY=your_key_here
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your_anon_key
   SUPABASE_SERVICE_KEY=your_service_role_key

STEP 4: INSTALL DEPENDENCIES
   $ pip install -r requirements.txt

   This will install:
   - Flask 3.0.0
   - Flask-CORS 4.0.0
   - python-dotenv 1.0.0
   - google-generativeai 0.3.0
   - supabase 2.3.4
   - requests 2.31.0

STEP 5: SET UP DATABASE
Option A - Automatic (Recommended):
   $ python seed_data.py
   
   This will create tables and populate placeholder data.

Option B - Manual:
   1. Go to Supabase Dashboard
   2. Open SQL Editor
   3. Create new query
   4. Copy content from: ../supabase/migrations/001_create_cybersecurity_tables.sql
   5. Execute query

STEP 6: START THE SERVER
   $ python app.py
   
   Output should show:
   * Running on http://0.0.0.0:5000
   * Debug mode: on

STEP 7: TEST THE INSTALLATION
Open a new terminal window and test:

a) Health Check:
   $ curl http://localhost:5000/api/health
   Response: {"status": "healthy", "service": "cybersecurity_chatbot"}

b) List Countries:
   $ curl http://localhost:5000/api/countries
   Response: {"countries": {"NYC": "...", "GERMANY": "...", "SOUTH_KOREA": "..."}}

c) Create Session:
   $ curl -X POST http://localhost:5000/api/session/create \
     -H "Content-Type: application/json" \
     -d '{"country_code":"NYC"}'
   Response: {"session_id": "...", "user_id": "...", "message": "Welcome!..."}

d) Send Message (replace SESSION_ID):
   $ curl -X POST http://localhost:5000/api/chat \
     -H "Content-Type: application/json" \
     -d '{"session_id":"SESSION_ID","message":"What is SHIELD?"}'
   Response: {"response": "The SHIELD Act...", "success": true}

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "ModuleNotFoundError: No module named 'flask'"
SOLUTION: 
   $ pip install -r requirements.txt
   Make sure you're in the backend directory

ISSUE: "GEMINI_API_KEY not found"
SOLUTION:
   1. Check .env file exists: ls -la .env
   2. Check it has GEMINI_API_KEY=your_key
   3. Verify the key is correct from https://ai.google.dev/

ISSUE: "Connection to Supabase failed"
SOLUTION:
   1. Check .env has correct SUPABASE_URL (includes https://)
   2. Check SUPABASE_KEY is correct (anon key, not service key)
   3. Verify Supabase project is active

ISSUE: "Address already in use"
SOLUTION:
   1. Change PORT in .env to different value (e.g., 5001)
   2. Or kill process: kill -9 $(lsof -t -i :5000)

ISSUE: "No tables in Supabase"
SOLUTION:
   1. Run: python seed_data.py
   2. Or manually execute SQL migration in Supabase editor

ISSUE: "API returns 500 error"
SOLUTION:
   1. Check Flask debug output in terminal
   2. Verify database connection
   3. Check API key validity
   4. Review .env configuration
