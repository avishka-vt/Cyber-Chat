API ENDPOINTS QUICK REFERENCE
================================================================================

1. Health Check
   GET /api/health
   Purpose: Check server status
   Response: {"status": "healthy", "service": "cybersecurity_chatbot"}

2. List Countries
   GET /api/countries
   Purpose: Get available countries
   Response: {"countries": {"NYC": "...", "GERMANY": "...", "SOUTH_KOREA": "..."}}

3. Create Session
   POST /api/session/create
   Body: {"country_code": "NYC"}
   Response: {"session_id": "...", "user_id": "...", "message": "Welcome!..."}

4. Send Message
   POST /api/chat
   Body: {"session_id": "...", "message": "What is SHIELD?"}
   Response: {"response": "...", "country": "NYC", "success": true}

5. Switch Country
   POST /api/session/{id}/switch-country
   Body: {"country_code": "GERMANY"}
   Response: {"success": true, "message": "Switched...", "country_code": "GERMANY"}

6. Get Session Info
   GET /api/session/{id}/info
   Response: {"user_id": "...", "country_code": "...", "created_at": "..."}

7. End Session
   POST /api/session/{id}/end
   Response: {"success": true, "message": "Session ended"}

PRODUCTION DEPLOYMENT
================================================================================

For production use:

1. Update .env:
   - Set FLASK_ENV=production
   - Set FLASK_DEBUG=False
   - Use production API keys

2. Use Production WSGI Server:
   pip install gunicorn
   gunicorn -w 4 -b 0.0.0.0:5000 app:app

3. Deploy Options:
   - Heroku: git push heroku main
   - AWS: Use Lambda with Zappa or EC2
   - Google Cloud: gcloud app deploy
   - Docker: Build and deploy container

4. Security:
   - Enable HTTPS/SSL
   - Set up rate limiting
   - Enable monitoring
   - Configure backup strategy
